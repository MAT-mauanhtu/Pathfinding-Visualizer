English:
Developed a Python application to visualize pathfinding algorithms such as A*, BFS, and DFS.
  - Built an interactive grid interface using Pygame, allowing users to set start/end points and create obstacles.
  - Demonstrated the efficiency of different algorithms through real-time visualization.
  How to use:
    Left Mouse:
    Click to set Start, End, and Barrier points.
    Right Mouse:
    Click to clear set points.
    SPACE key:
    Start path finding algorithm.
    C key:
    Clear entire grid and restart.

  Vietnamese:
  Phát triển một ứng dụng Python để trực quan hóa các thuật toán tìm đường như A*, BFS và DFS.
  - Xây dựng giao diện lưới tương tác bằng Pygame, cho phép người dùng đặt điểm bắt đầu/kết thúc và tạo chướng ngại vật.
  - Chứng minh hiệu quả của các thuật toán khác nhau thông qua trực quan hóa thời gian thực.
  Cách sử dụng:
  Chuột trái:
  Nhấp để đặt điểm Bắt đầu, Kết thúc và Rào cản.
  Chuột phải:
  Nhấp để xóa các điểm đã đặt.
  Phím SPACE:
  Bắt đầu thuật toán tìm đường.
  Phím C:
  Xóa toàn bộ lưới và khởi động lại.
